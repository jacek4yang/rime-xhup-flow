# 小鹤双拼键盘布局规范数据

本目录保存 XHUP Flow 的小鹤双拼键盘布局**唯一事实来源**(canonical data)。未来的 Rust 生成器、分析器、Rime 产物与 trainer 均以此为准。

## 文件与格式

纯 TSV(UTF-8、LF 行尾、无表头、无注释),每行恰好两个 TAB 分隔字段,按首列字典序升序:

- `initials.tsv`:`声母 → 键位`,23 行。所有单声母恒等映射显式列出;特殊双声母 `zh→v`、`ch→i`、`sh→u`。
- `finals.tsv`:`韵母 → 键位`,33 行。一个键可对应多个韵母(如 `ing`/`uai` 同键 `k`、`iong`/`ong` 同键 `s`);每个韵母独占一行;`ue` 与 `ve`(üe)显式分行。
- `zero_initials.tsv`:`零声母音节 → 两键编码`,12 行。规则:单字母韵母重复韵母键(`a→aa`);双字母韵母按原样两键(`an→an`);三字母韵母取首字母 + 韵母键(`ang→ah`)。

## 规范化规则

- 全部小写 ASCII;无声调、无音调符号、无大写。
- ü 族用 ASCII `v` 表示(如 `ve`),不存 Unicode `ü`。
- 无尾随空白;每行一个映射;确定性排序。

## 来源与一致性

映射为事实性键盘布局数据,经以下来源交叉核实,无分歧:

1. 小鹤音形官方文档「双拼方案」(看云,`yphy/xhyx`):官方记忆口诀与零声母规则。
2. ulpb.app 小鹤双拼键位表(独立实现,交叉核对)。
3. 本仓库 `flypy_chars.dict.yaml` 既有编码作为一致性证据(如 中=vs、张=vh、昂=ah、英=yk、女=nv)。

本数据仅描述键盘布局:不做普通话音节合法性校验,不涵盖形码、声调或候选排序。
