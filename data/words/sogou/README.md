# 搜狗细胞词库聚合层(所有者决策入库)

搜狗细胞词库(SogouWan .scel)全站抓取的确定性聚合快照,按
(词, 规范读音序列) semantic entry 归一化到本项目规范读音,逐字校验
8105 规范清单与规范读音。

## 来源与提取

- 来源:搜狗细胞词库 https://pinyin.sogou.com/dict/(2026-09-13 全站抓取,
  109 分类、6279 个 .scel;下载 5880 成功)
- 提取工具:深蓝词库转换器(scel → 全拼),随后按 data/hanzi/readings.tsv
  规范读音过滤、聚合、去重、排序
- 过滤流水线:字 ∈ 8105 规范清单;音节数 = 字数;每音节 ∈ 该字规范读音集合
- 输入快照 SHA-256(全量 4,330,803 行合并文本):

## 分片结构

词数据量大,按 250,000 行/片切分,UTF-8 无 BOM、LF 换行、TAB 分隔:

- sogou_cell_01..09.tsv:2~4 字词(2,082,859 条),**绑定
  xhup-generator 词码投影**(超出 wanxiang_extended 的增量 168.9 万条)
- sogou_long_01..09.tsv:5 字及以上长词(2,170,395 条),超出词码模型
  (词码最多 4 字 × 2 键),仅作参考层数据保留,不参与生成

每分片 SHA-256 见本目录 MANIFEST.tsv(由提取器确定性再生成);
全部分片均为无调规范读音。

## 序列化

词长升序 → 词 Unicode 码点升序 → 读音序列升序;全部来源分数为 1
(细胞词库无真实词频),运行时词频由 Rime 用户词频与万象层权重承载。
