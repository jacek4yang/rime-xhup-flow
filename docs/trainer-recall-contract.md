# Trainer 回忆与提示契约

学习目的与十二种题池模式分离：默认「盲打测试」，可在设置切换「对照学习」。旧设置即使选择始终显示提示，也不会自动进入对照学习。

盲打题只显示目标文本、码位和已接受输入。等待、错键和教学暂停不会自动挂载拼音、完整编码或下一键高亮；显式「查看解析」获得本题答案权限，并把该题记为求助。重试不清除错误或求助记录。对照学习遵守 always/on-delay/on-error/hidden，自动揭示同样不能算独立回忆。

共享 `practice/hints.ts` 决定权限。迟疑门限为每题活跃2000ms，暂停不累计，新题归零，重试保留累计时间。完成事件分开 `practiceMs`（未结算日统计增量）和 `questionMs`（整题所有活跃片段）；统计耗时使用后者，不因暂停丢失此前时间。

编码路线必须匹配完整已输入前缀，不能把两条合法码的局部字符拼成非法码。退格到共享前缀恢复主练优先；重试恢复主练且保留错误。教学卡片接收当前路线和可空期望键，不再从主练码索引备用路线位置。
